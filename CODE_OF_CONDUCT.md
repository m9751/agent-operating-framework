# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

## Summary

Be respectful, constructive, and focused on the work. Harassment, dismissiveness, and personal attacks are not acceptable.

## Scope

Applies to all project spaces: issues, PRs, discussions, and any public communication representing this project.

## Enforcement

Violations can be reported by opening a private GitHub issue or contacting the maintainer directly. All reports will be reviewed and responded to.
